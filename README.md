# Simulador de Ataques de Força Bruta em Python

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de demonstrar, de forma prática e didática, como ataques de força bruta podem explorar sistemas de autenticação que não possuem mecanismos de proteção adequados.

O programa simula dois cenários: um sistema vulnerável, que permite tentativas ilimitadas de login, e um sistema protegido, que aplica um limite de tentativas incorretas.

## Tecnologias utilizadas

- Python
- Visual Studio Code
- Git
- GitHub

## Funcionalidades

- Simulação de tentativas de autenticação.
- Demonstração de um sistema vulnerável.
- Implementação de limite de tentativas.
- Simulação de bloqueio de login.
- Registro de eventos em arquivo de log.

## Objetivo educacional

Demonstrar a importância de mecanismos de segurança como limitação de tentativas, monitoramento de eventos, políticas de senha e proteção contra acessos não autorizados.

## Conclusão

O projeto demonstra que sistemas de autenticação sem mecanismos de proteção estão mais suscetíveis a ataques de força bruta. A implementação de limites de tentativas e monitoramento de eventos representa uma medida importante para aumentar a segurança dos sistemas.

Este projeto possui finalidade exclusivamente educacional e funciona por meio de simulações locais, sem realizar ataques a sistemas externos.
